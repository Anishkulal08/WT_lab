Introduction to HTML

1. Introduction

HTML stands for HyperText Markup Language. It is used to create and design web pages.


2. HTML Formatting Commands
Formatting HTML Tag Example Purpose
Bold <b> Bold Text Makes text bold
Strong <strong> Strong Text Shows important text
Italic <i> Italic Text Makes text italic
Emphasized <em> Emphasized Text Emphasizes text
Underlined <u> Underlined Text Underlines text
Highlighted <mark> Highlighted Text Highlights text
Small <small> Small Text Displays smaller text
Deleted <del> Deleted Text Shows deleted text
Inserted <ins> Inserted Text Shows inserted text
Subscript <sub> H2O Displays text below the baseline
Superscript <sup> x2 Displays text above the baseline
